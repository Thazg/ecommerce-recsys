    Item and category codes are anonymized dataset identifiers. Product names, prices and images are not available. Expand a row to inspect retrieval sources.

    Reading the output

    One snapshot.
    Two stages.

    01 / Retrieve eligible products

    For returning users, ItemKNN, ALS, category popularity, recent popularity and global popularity contribute candidates. Reciprocal rank fusion (RRF) combines the source lists into a pool of up to 1,000 unseen items.

    02 / Compare the ordering

    The learned ranker reorders the same pool using source evidence and cutoff-time interaction features. Switch to RRF to inspect retrieval order. First-visit recommendations use the locked recent-popularity route.

    What these examples establish

    The five exported traces reproduce sealed model references exactly. The four fixed returning-user examples each have one previously seen item; this is not a representative activity sample or an accuracy estimate. Source ranks show where retrieval systems placed an item; they are not probabilities or causal explanations.

    Evaluation and service limits

    The separate nine-fold rolling benchmark uses chronological development and post-selection diagnostics. Folds 5–9 are not blind validation. The complete API remains local; measured serving memory exceeds the 2 GiB project target. This static showcase does not establish production readiness.

    Traceable to the model.

    Exported outputs retain their snapshot identity. No model weights, raw user IDs, future targets or credentials are delivered to this page.
